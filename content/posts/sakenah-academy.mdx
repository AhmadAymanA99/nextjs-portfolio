## The problem

Sakenah is an Arabic online academy for psychology, psychotherapy and mental health, aimed at both professionals and the public. The catalogue kept growing, so every new course had to be quick to publish without custom pages, and course pages had to rank in Arabic search.

## What I did

As part of the Softera team I worked on:

• A reusable course architecture, so new courses are content, not code
• REST API integration for courses, enrolment and accounts
• SEO and performance: server-side rendering and fast first loads
• Exposing platform APIs as AI tools with FastMCP

## The result

The academy serves **10K+ active users** across **50+ courses**, with **99.9% uptime**.
